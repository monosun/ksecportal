# KSecPortal v1.42.3 릴리즈 노트

**릴리즈 일자**: 2026-10-28

v1.42.2 에서 누락된 **쓰기·조회 API 권한 검사**를 추가하고, 엑셀·CSV 내려받기의 **수식 삽입(Formula Injection)** 취약점을 수정한 보안 패치입니다.
DB 변경은 없습니다.

---

## 보안 수정

### 1. 쓰기 API 권한 누락 (A01 접근 통제 실패)

권한관리에서 USER 의 메뉴 권한을 모두 해제해도, 일반 USER 계정이 아래 API 를 직접 호출하면 데이터를 등록·변경할 수 있었습니다.

| 대상 | 영향 | 수정 |
|------|------|------|
| 정보보호 관리체계 > **위협관리** 추가·수정·삭제·기본값 불러오기 | 위협 카탈로그(위험평가의 기준 데이터) 변조·삭제 | 메뉴 권한 `threats` 쓰기/삭제 검사 |
| 정보보호 관리체계 > **취약점관리** 등록, 댓글 작성·수정·삭제 | 취약점 허위 등록, 댓글 작성 | 메뉴 권한 `vulnerabilities` 쓰기 검사 (댓글은 기존 작성자 본인 확인 유지) |
| 보안운영 > **보안성심의** 요청 등록·첨부 교체 | 권한 없는 사용자의 심의 요청 | 메뉴 권한 `security_reviews` 쓰기 검사 |
| 보안운영 > **인시던트** 등록 | 권한 없는 사용자의 인시던트 등록 | 메뉴 권한 `incidents` 쓰기 검사 |

> **동작 변경** — 지금까지는 기본 USER 도 보안성 심의를 요청할 수 있었습니다.
> 임직원이 심의를 요청하게 하려면 **관리 > 권한관리**에서 USER(또는 커스텀 Role)에 `보안성심의` **쓰기** 권한을 켜 주세요.

### 2. 조회 API 메뉴 권한 검사

위 4개 메뉴는 조회(목록·상세·댓글·첨부 다운로드)도 메뉴 권한을 확인합니다(`@menuAuth.canRead(...)`).
같은 데이터를 쓰는 화면은 함께 허용합니다 — 위협 목록은 `위험평가`, 취약점·인시던트는 각 `대시보드` 메뉴 권한으로도 조회할 수 있습니다.
메인 대시보드의 취약점 통계(건수)는 그대로 열려 있습니다.

### 3. 메뉴 화면 직접 접근

화면 라우터가 메뉴 권한을 확인하지 않아, 메뉴가 숨겨져 있어도 주소를 직접 입력하거나 `/api/auth/me`·`/api/auth/my-permissions` 응답을 변조하면 화면에 들어갈 수 있었습니다.

- 메뉴 경로(하위 경로 포함)로 이동할 때 조회 권한이 없으면 대시보드로 돌려보냅니다.
- 화면 진입 차단은 사용 편의용이며, 데이터 접근은 위 1·2의 **서버 권한 검사**가 막습니다. 응답을 변조해 화면에 들어가도 권한 없는 조회·변경은 `403` 입니다.

### 4. 엑셀·CSV 수식 삽입 (Formula Injection)

위협명·설명 등에 `=1+1` 처럼 수식을 입력하면, 내려받은 엑셀에서 셀을 편집(활성화)하는 순간 수식이 실행될 수 있었습니다.
`= + - @`·탭·CR 로 시작하는 값을 텍스트로 고정합니다.

| 형식 | 방식 | 대상 |
|------|------|------|
| 서버 생성 xlsx | 값은 그대로 두고 "텍스트로 표시(quotePrefix)" 서식 적용 — 다시 가져오기해도 내용 동일 | 결과 리포트 엑셀(`ExcelWriter`), 위험평가 엑셀, ISMS-P 증적·매핑 양식 |
| CSV | 값 앞에 작은따옴표(`'`) 추가 | 취약점·자산·정책·인시던트·사용자 CSV, ISMS-P 증적 CSV, ISMS 결함 CSV |
| 브라우저 생성 xlsx | 값 앞에 작은따옴표(`'`) 추가 | 위협 카탈로그, 퀴즈 문항, 법령검토 엑셀 |

- 퀴즈 문항 일괄등록은 내보낼 때 붙인 `'` 를 자동으로 떼어, 내보낸 파일을 그대로 다시 올릴 수 있습니다.
- 리포트 CSV 에서 제목 외 칸(IP 주소·부서 등)에 쉼표가 있으면 열이 밀리던 문제도 함께 고쳤습니다.

## 영향 범위

- **DB 변경 없음**, 마이그레이션 불필요
- API: 권한 없는 요청은 `403`. 권한관리에서 쓰기 권한을 준 USER·커스텀 Role 은 그대로 동작합니다
- 기본 USER 의 보안성 심의 요청이 막힙니다(위 "동작 변경" 참고)
