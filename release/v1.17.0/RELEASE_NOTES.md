# v1.17.0 릴리즈 노트

**릴리즈 일자**: 2026-07-24

**보안성 심의** 메뉴를 신설하고, 개인정보 현황보고서를 그래프 중심으로 바꿨습니다.
소스 취약점 점검(SAST) 지적사항을 조치하고, CVE·CWE 설명 팝업과 보안문서 파일 미리보기를 추가했습니다.

## 신규 기능

### 보안성 심의 (보안 운영 > 보안성 심의)

신규 시스템 구축·변경 시 **설계 단계에서 보안 요구사항 충족 여부를 검토**하는 절차를 관리합니다.

```
요청 접수 → 검토중 → (보완 요청) → 심의 완료(승인 / 조건부 승인 / 반려)
```

- **심의 요청**: 제목·대상 시스템·심의 구분(신규구축/변경·고도화/외부연계/폐기)·요청부서·오픈예정일·개요, **개인정보 처리 여부·인터넷 공개 여부** 체크, 설계서 첨부
- 요청 등록 시 **기본 검토 체크리스트 20개 항목 자동 생성** — 인증·권한 / 접근통제 / 암호화 / 개인정보 / 로그·감사 / 개발보안 / 운영·보안설정 (항목별 검토 기준 포함)
- **검토**: 항목별 적합·부적합·해당없음 판정과 의견 기록, 심의별 항목 추가·삭제, 첫 판정 시 상태 자동 전환(요청 접수 → 검토중)
- **심의 결과**: 승인 / 조건부 승인 / 반려 + 심의 의견. **미검토 항목이 남으면 결과 등록을 차단**하며, 재검토로 되돌리기 지원
- 현황 카드(요청/검토중/보완/완료/승인/조건부·반려) 클릭 필터, 검토 진행률·부적합 건수 표시
- 심의 요청은 로그인 사용자 누구나, **검토·결과·삭제는 MANAGER 이상**. 등록·결과 확정·삭제는 감사로그 기록

### 개인정보 현황보고서 — 그래프 시각화

숫자 나열이던 화면을 보고용 그래프 중심으로 재구성했습니다.

- **즉시 조치 필요** 배너 — 만료 경과·신고기한 경과·처리기한 초과·미종결·미점검·DPIA 위험높음 중 **0이 아닌 항목만** 상단 집약(모두 0이면 "이상 없음")
- **핵심 지표 4타일** + **이행률 미터 4종**(수탁사 점검·파기·DPIA·안전조치 — 90%↑ 녹색 / 70%↑ 노랑 / 미만 빨강, 비율과 `완료/전체` 병기)
- **가로 누적 막대 7종**(처리업무·파일·제3자제공·유출사고·보유기간·파기·권리행사) — 색 범례·건수·호버 툴팁
- **유형별 순위 막대**(권리행사·안전조치) — 단일 색, 큰 값 순, 값 직접 표기
- **표로 보기** 토글 — 같은 수치를 표로 확인(값 검증·접근성)
- **PDF 다운로드가 화면과 같은 구성으로 출력**됩니다(조치필요 → 핵심지표 → 이행률 미터 → 영역별 누적막대 → 유형별 막대, 마지막 장에 상세 수치 표 부록)

### 소스 취약점 점검 — PDF 보고서 · CWE 설명

- 점검 상세에 **PDF 보고서** 버튼 — 가로 A4로 요약·심각도/카테고리 분포 막대·전체 발견 목록 출력 (MANAGER+)
- 발견 내역에 **CWE 열**(CVE 앞) 추가 — 클릭하면 팝업으로 **무엇인가 / 위험 / 조치 방법**과 MITRE 원문 링크 제공(엔진이 쓰는 CWE 13종 수록)
- **오탐 억제 주석** 지원 — 소스에 `// sast:ignore 사유`를 남기면 해당 줄을 건너뜁니다

### 취약점 관리 — CVE 설명 팝업

목록의 CVE ID·상세의 CVE 뱃지를 클릭하면 **NVD 조회 기반 설명·심각도·CVSS 점수**를 팝업으로 표시합니다(원문 링크 포함).

### 보안문서 — 파일 미리보기

파일명을 클릭하면 내려받지 않고 팝업으로 내용을 확인합니다(버전 이력에도 미리보기 버튼).

| 형식 | 미리보기 |
|------|----------|
| PDF | 문서 뷰어 |
| 이미지(jpg·png·gif·webp) | 원본 비율 표시 |
| 엑셀(xlsx·xls)·CSV | **표로 변환**, 시트 탭 전환(첫 300행) |
| 텍스트(txt) | 본문 표시 |
| 워드·PPT·ZIP | 안내 문구 + 다운로드 |

### 보안 정책 — 다중 선택 삭제

목록 체크박스로 여러 정책을 선택해 한 번에 삭제합니다(**ADMIN 전용**, 페이지를 넘겨도 선택 유지, 확인 창에 대상 제목 표시).

### IT 및 정보보호 교육 — 검색 필터

검색어(제목+**설명**)·이수구분(필수/선택)·교육유형(영상/문서/퀴즈)·이수여부(이수/미이수) 필터와 결과 건수·초기화 버튼을 추가했습니다.

## 개선 · 버그픽스

- **보안솔루션 연동 개발 가이드** 신규 — `docs/security-solution-integration-guide.md`. 연동 방식·필드/심각도 매핑 규격·솔루션 유형별 예시·재시도/중복방지·보안 요구사항·예제 코드·체크리스트와 **현재 구현 제약**(Push 전용·단건 등록·`apiKey`는 이벤트 인증에 미사용) 명시
- **RSS 뉴스 정리** — 요약에 섞여 오던 `<a href=…>` 등 HTML 태그·엔티티 제거. 구글 뉴스처럼 **요약이 제목과 같은 문장**(제목에서 `-` 구분자만 빠진 형태)인 피드는 요약을 표시하지 않아 같은 문장이 두 줄로 보이던 문제 해결
- 메뉴 그룹 **문서관리 → "보안 가이드 및 자료"** 로 명칭 변경
- **보안문서 감사로그 추가** — 등록·버전추가·삭제(전체/개별)를 기록해 문서 변경 이력을 추적할 수 있습니다
- 자산 목록 필터 변경 시 첫 페이지로 이동, 정책 삭제 후 빈 페이지 방지 등 목록 동작 정리

## 보안 조치 (SAST 지적사항)

| 지적 | 조치 |
|------|------|
| **CWE-89** SQL 문자열 결합 (`BackupService`) | 백업 파일에서 오는 **테이블·컬럼 식별자를 형식 검증**(`quoteIdent`) 후에만 SQL에 사용, 존재하지 않는 컬럼이면 복원 중단. 값은 기존대로 전부 바인딩 파라미터 |
| **CWE-611** XXE (`RssService`) | DOCTYPE 차단에 더해 외부 일반/파라미터 엔티티·외부 DTD 차단, `SECURE_PROCESSING`, `ACCESS_EXTERNAL_DTD/SCHEMA` 차단, XInclude off, EntityResolver 무력화 |
| **CWE-330** 안전하지 않은 난수 (프론트 3곳) | `utils/secureRandom.js` 신설 — `crypto.getRandomValues` 기반 **편향 없는 난수·Fisher–Yates 셔플·randomId**. 교육 문항 무작위 추출·엔트리 ID 생성에 적용 |
| **CWE-295** TLS 검증 비활성화 (`SastEngine`) | **오탐** — 스캐너가 자기 탐지 규칙 문자열을 검출한 것. 억제 주석(`// sast:ignore`) 기능을 추가하고 사유와 함께 표시 |

## 데이터베이스 · API

- 신규 테이블 **`security_reviews`**, **`security_review_items`** (ddl-auto 자동 생성 — 마이그레이션 불요)

| 메서드 | 경로 | 설명 |
|--------|------|------|
| `GET/POST` | `/api/security-reviews` | 심의 목록·요청 등록(multipart) |
| `GET` | `/api/security-reviews/summary` | 상태·결과별 건수 |
| `PATCH` | `/api/security-reviews/{id}` | 요청 정보·상태 수정 (MANAGER+) |
| `POST` | `/api/security-reviews/{id}/decision` | 심의 결과 등록 (MANAGER+) |
| `POST/PATCH/DELETE` | `/api/security-reviews/{id}/items`, `/items/{itemId}` | 검토 항목 관리 (MANAGER+) |
| `GET/POST` | `/api/security-reviews/{id}/file` | 설계서 다운로드·첨부 |
| `GET` | `/api/reports/source-scan/{scanId}/pdf` | SAST 결과 보고서 (MANAGER+) |
| `DELETE` | `/api/policies?ids=1,2,3` | 정책 일괄 삭제 (ADMIN) |

- `GET /api/training/courses` 에 `mandatory`, `contentType` 필터 추가 (검색어가 설명까지 대상)
- RBAC 메뉴키 **`security_reviews`** 추가

## 인프라 변경

- **nginx CSP 완화(1항목)** — PDF·이미지 미리보기를 위해 `frame-src 'self' blob:; object-src 'self' blob:` 추가. 외부 출처는 여전히 전부 차단이며 `frame-ancestors 'none'`(클릭재킹 방어)은 유지됩니다.

```bash
docker compose build backend frontend
docker compose up -d backend frontend
```
