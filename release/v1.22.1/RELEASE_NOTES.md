# v1.22.1 릴리즈 노트

**릴리즈 일자**: 2026-07-25

운영현황관리 요약의 **월별 막대가 제목을 가리던 표시 오류**를 수정했습니다. 프론트엔드 전용 변경입니다.

## 버그 수정

### 운영현황관리 — 월별 계획 대비 이행 막대가 제목을 덮음

**증상**
보안 운영 > 운영현황관리에서 **기본 항목 불러오기**로 항목을 채우면, 요약 카드의 **"월별 계획 대비 이행"** 글자가 아래 막대 그래프에 부분적으로 가려졌습니다.

**원인**
막대 행에 고정 높이 `h-10`(40px)을 줬는데, 한 열이 실제로 차지하는 높이는 그보다 컸습니다.

```
막대 최대 36px + 간격 2px + 월 숫자 ≈ 11px  =  약 49px  >  40px
```

행이 `items-end`(아래 정렬)라 넘친 9px가 **위쪽으로 밀려나** 바로 위의 제목을 덮었습니다.
계획 건수가 적을 때는 막대가 낮아 잘 드러나지 않다가, 기본 항목 45건을 불러와 월별 계획 막대가 최대 높이에 가까워지면서 눈에 띄었습니다.

**수정**
- 막대가 그려지는 **트랙 높이를 36px로 고정**하고, 막대는 그 안에서 아래 정렬되도록 했습니다.
- **월 숫자를 트랙 바깥(아래)** 으로 분리해 막대 높이와 무관하게 자리를 차지하도록 했습니다.
- 바깥 행의 고정 높이를 제거해 내용 높이만큼 자연스럽게 늘어나게 했습니다.
- 막대 최대 높이를 트랙 높이 상수(`BAR_TRACK`)에서 계산하도록 묶어, 앞으로 높이를 바꿔도 다시 어긋나지 않습니다.
