# KSecPortal v1.32.2 릴리즈 노트

**릴리즈 일자**: 2026-08-10

대시보드 **법령 개정** 위젯이 일부 법령을 빠뜨리고 표시하던 문제를 고쳤습니다.

---

## 버그 수정

### 법령 개정 위젯 — 조회 실패가 "개정 없음"으로 오인 캐시되던 문제

- 위젯은 등록된 법령들을 최대 4개씩 동시에 조회해 결과를 12시간 캐시합니다. 이 과정에서 특정 법령의 조회가 일시적으로 실패(네트워크·law.go.kr 응답 지연 등)해도, 실패와 "해당 법령의 개정 이력 없음"을 구분하지 못하고 **똑같이 캐시**해버려 조회 기간을 아무리 늘려도 그 법령만 계속 목록에서 빠지는 문제가 있었습니다.
- `legalApiService.js`의 `fetchLawMeta`가 요청 실패 시 `null`을 반환하던 것을 **예외를 던지도록 변경**해 "결과 없음"과 구분하고, `DashboardView.vue`의 조회 로직도 실패한 항목은 캐시하지 않고 다음 로드 시 재시도하도록 수정.
- 기존에 이미 잘못 캐시된 항목은 이번 배포로 자동 해소되지 않습니다 — 영향 받은 사용자는 브라우저 콘솔에서 `localStorage.removeItem('legal-meta-cache-v1')` 실행 후 새로고침하면 즉시 재조회됩니다(최대 12시간 후 자동 만료로도 해소됨).
- Excel 다운로드·법령검토 모달(`fetchLawByName`·`fetchLawFull`)은 기존과 동일하게 실패 시 조용히 빈 결과를 반환(동작 변화 없음).

## 업그레이드

```bash
docker compose build frontend
docker compose up -d frontend
```

백엔드·DB 변경 없음.
