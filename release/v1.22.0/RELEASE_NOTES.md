# v1.22.0 릴리즈 노트

**릴리즈 일자**: 2026-07-25

보안 용어집에 **엑셀 일괄등록**을 추가했습니다.
용어를 한 건씩 등록하지 않고, 기존 자료를 서식에 맞춰 한 번에 올릴 수 있습니다.

## 신규 기능

### 관리 > 코드 관리 > 용어집 — 엑셀 일괄등록

**용어 추가** 옆에 **엑셀 일괄등록** 버튼이 추가되었습니다. (ADMIN 전용)

#### 템플릿

**용어집 템플릿 다운로드 (.xlsx)** 로 서식을 받습니다. 헤더와 예시 2행이 채워져 있고, 열 너비·틀 고정이 적용되어 있습니다.

| 열 | 내용 | 비고 |
|----|------|------|
| 한글 용어* | `다중요소인증` | **필수** — 중복 판단 기준 |
| 영문 표기 | `Multi-Factor Authentication` | |
| 약어 | `MFA` | |
| 분류 | `접근통제` | |
| 의미 | `서로 다른 인증 요소를 두 개 이상 사용해 신원을 확인하는 방식` | |
| 관련 키워드 | `OTP, 생체인증` | 쉼표로 구분 |
| 정렬 순서 | `1` | 비우면 자동 부여 |
| 사용여부(Y/N) | `Y` | 비우면 사용. `Y/N` · `사용/미사용` · `true/false` · `1/0` 허용 |

#### 중복 처리 — 덮어쓰기 옵션

**한글 용어**를 키로 삼아 이미 등록된 용어인지 판단합니다(대소문자 무시).

| 옵션 | 동작 |
|------|------|
| **덮어쓰기 해제** (기본) | 이미 있는 용어는 **건너뜁니다**. 새 용어만 추가할 때 씁니다 |
| **덮어쓰기 선택** | 이미 있는 용어의 내용을 **갱신합니다**. 단 **빈 칸은 기존 값을 지우지 않습니다**(채운 칸만 반영) |

- 파일 안에서 같은 용어가 반복되면 **첫 행만** 반영합니다.
- 한글 용어가 비어 있는 행은 실패로 처리하고 사유를 표시합니다.

#### 결과 표시

업로드가 끝나면 **전체 · 등록 · 갱신 · 중복 제외 · 실패** 건수와, 실패한 행의 번호·사유가 목록으로 표시됩니다.

## 변경 사항

### 공용 BulkImportModal 확장

여러 화면이 함께 쓰는 일괄등록 모달에 두 가지가 추가되었습니다. 기존 호출부는 영향을 받지 않습니다.

- **`options` 슬롯** — 화면별 추가 옵션(여기서는 덮어쓰기 체크박스)을 파일 선택 아래에 넣을 수 있습니다.
- **갱신 건수 표시** — 결과에 `updated` 가 있으면 파란색으로 **갱신 N건**을 함께 보여줍니다.

## API 변경

| 메서드 | 경로 | 설명 |
|--------|------|------|
| `GET` | `/api/glossary/bulk/template` | 엑셀 템플릿 다운로드 (ADMIN) |
| `POST` | `/api/glossary/bulk?overwrite=` | 엑셀 일괄 등록 (ADMIN, `overwrite` 기본 false) |

응답은 `{ total, success, updated, skipped, failed, errors: [{ row, message }] }` 형태입니다.
일괄등록 결과는 **감사로그**(`GLOSSARY_TERM`)에 신규·갱신·제외·실패 건수와 함께 기록됩니다.
