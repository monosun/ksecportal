# KSecPortal v1.45.3 릴리즈 노트

**릴리즈 일자**: 2026-11-10

**[보안 강화]** 관리자 MFA 필수를 기본값으로 켜고, 화면의 개발자 도구 단축키·우클릭 메뉴를 막습니다.

---

## 1. 관리자 MFA 필수 — 기본 켜짐

- 설정관리 > 보안 설정의 **관리자 계정 MFA 필수**가 저장된 값이 없으면 **켜짐**으로 동작합니다(이전: 꺼짐).
- MFA 를 등록하지 않은 관리자(ADMIN)는 로그인 후 설정 화면으로 이동되며, MFA 를 등록할 때까지 변경 작업(`POST·PUT·PATCH·DELETE`)이 `403` 으로 거절됩니다. MFA 등록(`/auth/**`)은 허용되므로 잠기지 않습니다.
- Okta SSO 계정은 IdP 가 MFA 를 담당하므로 제외됩니다.
- 이미 이 설정을 **꺼짐으로 저장한** 설치는 저장값이 유지됩니다. 필요하면 보안 설정에서 다시 켜세요.

## 2. 개발자 도구 단축키·우클릭 메뉴 차단

- **F12**, **Ctrl+Shift+I/J/C**(macOS **Cmd+Option+I/J/C**) 단축키가 동작하지 않습니다. Ctrl+U(소스 보기)는 기존처럼 새로고침됩니다.
- 화면의 **우클릭 메뉴**(검사·페이지 소스 보기)를 막습니다. 입력칸에서는 붙여넣기 등을 위해 허용합니다.
- 브라우저 메뉴로 여는 개발자 도구까지 막는 장치는 아니며, 보안 통제는 서버에서 수행합니다.

## 3. 업그레이드

```bash
docker compose build backend frontend
docker compose up -d backend frontend
```

DB 변경 없음. 배포 후 브라우저 강력 새로고침(Ctrl+Shift+R)이 필요합니다.
**업그레이드 전에 MFA 를 등록하지 않은 관리자 계정이 있는지 확인하세요** — 업그레이드 직후 해당 계정은 MFA 등록 전까지 변경 작업을 할 수 없습니다.
