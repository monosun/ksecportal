# KSecPortal v1.44.2 릴리즈 노트

**릴리즈 일자**: 2026-11-08

**[보안 수정]** v1.44.1 이후 CodeQL 재검사에서 남은 항목(높음 1 · 중간 8)을 조치했습니다.

---

## 1. 관리자 승인 링크 화면 — 저장형 XSS · 오류 정보 노출 수정

관리자 승인 메일의 **승인/거부 링크**를 열면 보이는 결과 화면이 메시지를 HTML 이스케이프 없이 그대로 넣고 있었습니다.

- 결과 메시지에는 대상 사용자의 **이름·이메일**이 들어가는데, 이름은 회원가입 시 누구나 정할 수 있어
  이름에 스크립트를 넣으면 링크를 연 관리자 브라우저에서 실행될 수 있었습니다(저장형 XSS). → **모든 값을 이스케이프**
- 처리 중 오류가 나면 **예외 메시지를 그대로 화면에 표시**했습니다(CWE-209). → 정해진 안내 문구만 표시하고 상세는 서버 로그에 기록
  - 잘못된·없는 토큰: `유효하지 않거나 이미 처리된 링크입니다.`
  - 그 밖의 오류: `요청을 처리하지 못했습니다. 관리자에게 문의하세요.`

## 2. 법제처 API 프록시 — 오류 정보 노출 수정

분류되지 않은 연결 실패와 연결 테스트 응답 처리 실패에서 **예외 메시지를 응답에 포함**하던 것을 고정 안내 문구로 바꾸고
상세는 서버 로그로만 남깁니다. DNS 실패·시간 초과·연결 거부·HTTP 오류 코드 안내는 그대로입니다.

## 3. 정책 문서 장 제목 분석 — ReDoS 잔여 1건 제거

"지침명 - 제N장 …" 제목을 나누던 정규식(지침명 게으른 매칭)을 없애고, 대시 위치를 직접 찾아 뒤쪽이
`제N장`/`부칙` 으로 시작하는 첫 위치에서 나누도록 바꿨습니다(`ISMS-P 지침` 처럼 하이픈이 든 지침명 유지).
기존 정규식과 **결과가 같음을 표본 17건으로 검증**했고, 10만 자 입력도 수 ms 입니다.

## 4. CI 워크플로 최소 권한

`.github/workflows/ci.yml` 에 기본 `permissions: contents: read` 를 지정했습니다.
릴리즈 잡은 기존대로 자체 권한(`contents: write`, `packages: write`)을 씁니다.

## 5. 오탐 처리 (CodeQL)

아래 항목은 코드상 이미 방어되어 있으나 CodeQL 이 사용자 정의 검증을 인식하지 못하는 경우로, 사유를 남겨 오탐으로 종료했습니다.

| 항목 | 위치 | 사유 |
|------|------|------|
| SSRF | `SiteContentFetcher` | v1.44.1 `OutboundUrlGuard` 로 매 홉 내부망 차단 |
| SSRF | `LawApiProxyController` | 호스트 law.go.kr 고정, `target`·`mst`·검색어 검증 |
| SSRF | `GithubApiClient` | 다음 페이지는 설정된 API 주소로 시작하는 `Link` 만 추적, API 주소는 ADMIN 전용 설정 |
| CSRF 비활성 | `SecurityConfig` | 쿠키·세션 없는 Bearer JWT — v1.44.1 에서 종료한 항목이 주석 추가로 위치 지문이 바뀌어 다시 열림 |
