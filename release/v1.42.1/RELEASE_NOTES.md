교육 및 훈련 > 모의훈련의 악성메일 템플릿 **미리보기 화면에서 발생하던 XSS(저장형 크로스사이트 스크립팅) 취약점**을 수정했습니다. 프론트엔드 전용 변경입니다.

## 보안 수정

### 모의훈련 악성메일 템플릿 미리보기 XSS (Stored XSS)

**증상**

교육 및 훈련 > 모의 훈련 > 악성메일 템플릿에서 템플릿을 등록·수정할 때 메일 본문(HTML)에 임의의 HTML을 입력할 수 있었고, 이를 **미리보기** 화면에서 열람하면 삽입된 스크립트가 그대로 실행되었습니다.

```html
<img src=x onerror=alert(localStorage.getItem('token'))>
```

**영향**

`PhishingView.vue`의 미리보기 영역이 템플릿 본문을 검증 없이 `v-html`로 직접 렌더링하고 있었습니다. 로그인 시 발급되는 JWT가 `localStorage`에 저장되는 구조라, manager/admin 권한 사용자가 조작된 템플릿을 미리보기하는 순간 해당 세션의 토큰이 노출되고 이를 이용한 권한 상승(계정 탈취)으로 이어질 수 있었습니다.

**수정**

- 미리보기에 렌더링하기 전 템플릿 본문을 `DOMPurify.sanitize()`로 정제하도록 변경(`frontend/src/views/phishing/PhishingView.vue`). 기존에 프로젝트 내 다른 HTML 렌더링 화면(도움말, 보안정책 본문 등)에 쓰던 것과 동일한 방식입니다.
- `<script>` 태그와 `onerror`/`onclick` 등 이벤트 핸들러 속성이 제거되어 더 이상 임의 스크립트가 실행되지 않습니다. 템플릿 작성(입력)과 실제 발송 메일 렌더링(수신자 메일 클라이언트)은 영향받지 않습니다.

## 영향 범위
