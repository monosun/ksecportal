# KSecPortal v1.32.0 릴리즈 노트

**릴리즈 일자**: 2026-08-10
**구성**: 프론트엔드 · 문서 (백엔드·DB 변경 없음)

---

## 1. 좌측 메뉴 접기 — 화면 넓게 보기

Notion 처럼 **좌측 메뉴를 숨겨 본문을 화면 전체로 넓혀 볼 수 있습니다.** 목록·표가 넓은 화면(위험평가, 운영현황관리, 코드관리 등)에서 가로 공간을 220px 더 확보합니다.

| 동작 | 방법 |
|---|---|
| 접기 | 좌측 메뉴 상단 로고 오른쪽의 **«** 버튼 |
| 펴기 | 접힌 상태에서 화면 왼쪽 가장자리에 나타나는 **»** 탭 |
| 접기·펴기 | 단축키 `Ctrl` + `\` (어느 화면에서나 동작) |
| 접기·펴기 | 환경설정 > 화면 탭 > **화면 넓게 보기** 스위치 |

- 선택한 상태는 **브라우저(localStorage)에 저장**되어 다음 접속에도 유지됩니다. 서버에 저장하지 않으므로 사용자·브라우저별 설정입니다.
- **모바일·태블릿(좁은 화면)은 영향 없음** — 원래 좌측 메뉴가 숨겨져 있고 상단 햄버거 버튼으로 열고 닫으므로 이 설정을 적용하지 않습니다.

### 구현 메모

- 사이드바를 데스크톱에서도 `position: fixed` 로 바꾸고, 본문(`main`)이 **margin** 으로 자리를 비우도록 했습니다. padding 으로 처리하면 가로 스크롤 시 본문이 사이드바 밑으로 들어가므로 margin 을 사용해야 합니다.
- 사이드바는 `z-50` 이지만 DOM 상 본문보다 앞에 있어, 같은 `z-50` 인 화면 모달이 항상 사이드바 위에 표시됩니다(기존 동작 유지).

## 2. 브라우저 탭 제목에 로고 텍스트 적용

- 설정관리에서 지정한 **로고 텍스트(`login_logo_text`)가 브라우저 탭 제목에 반영**됩니다 (`<로고 텍스트> — 정보보호 포탈`). 기동 시·설정 저장 시 즉시 적용됩니다.
- 기본 제목의 옛 제품명을 교정했습니다 (`SecPortal` → `KSecPortal`).
- **버그 수정**: 개인 설정(localStorage)에 로고 텍스트가 없을 때 `'monosun'` 이 하드코딩 기본값으로 들어가 **설정관리에 저장한 로고 텍스트가 가려지던 문제**를 수정했습니다. 이제 개인 설정 → DB 설정 → `KSecPortal` 순으로 적용됩니다.

## 3. 부서 입력을 코드관리 값에서 선택

부서를 **자유입력으로만 받던 5개 화면**을 코드관리(`DEPARTMENT`, 12건) 목록에서 고를 수 있도록 바꿨습니다. 사용자 관리·회원가입은 이미 코드값 기반이어서 화면 간 기준이 어긋나 있던 것을 맞춘 것입니다.

| 화면 | 위치 |
|---|---|
| 자산 등록·수정 팝업 | `asset/AssetFormModal.vue` |
| 자산 등록 페이지(하위호환) | `asset/AssetFormView.vue` |
| 비상연락망 연락처 등록 | `emergency/EmergencyContactView.vue` |
| 모의 악성메일 훈련 대상자 등록 | `phishing/PhishingView.vue` |
| 보안성 심의 요청 부서 | `secreview/SecurityReviewView.vue` |

- 공용 컴포넌트 `components/DepartmentInput.vue` 신설. 코드값 조회는 **모듈 스코프에서 1회만** 수행하고 여러 화면·인스턴스가 공유합니다.
- **엄격한 `select` 가 아니라 목록 선택 + 직접 입력이 모두 되는 콤보박스(`datalist`)** 입니다. 운영 데이터의 부서 8건 중 6건(`CS운영팀`·`물류운영팀`·`재무회계팀`·`개통운영팀`·`IT&Security팀`·`개발파트`)이 코드값에 없어, select 로 바꾸면 수정 시 기존 값이 지워지기 때문입니다. 코드관리에 부서를 추가하면 그만큼 선택 목록이 늘어납니다.
- 코드값 조회에 실패해도 입력 자체는 막히지 않습니다(빈 목록으로 진행).

### 코드값으로 바꾸지 않은 항목

자산의 **자산유형·환경·상태·중요도(CIA)·클라우드 공급자**, 정책의 **카테고리·상태**, 취약점의 **심각도** 는 Java `enum` + DB `ENUM` 컬럼으로 고정된 값입니다(`Asset.AssetCategory`·`Policy.Category`·`Vulnerability.Severity` 등). 코드관리로 옮기면 관리자가 추가한 값을 백엔드가 거부하므로, 백엔드 enum·DB ENUM 마이그레이션을 동반해야 합니다 — 이번 릴리즈 범위에서 제외했습니다.

## 4. 비상연락망 — 대응반 담당자 성명 마스킹

비상연락망 목록에서 **개인 성명이 원문 그대로 노출**되던 것을 마스킹 처리했습니다.

| 연락 그룹 구분 | 이름 표시 |
|---|---|
| 대응반(내부 조직) · 협력사 | **마스킹** (예: 홍길동 → 홍*동) |
| 외부 기관 | 원문 유지 — `민원상담팀` 처럼 담당 부서명이 들어가므로 가릴 필요가 없고, 가리면 신고처를 알아볼 수 없습니다 |

- 마스킹 기준은 휴대전화·이메일과 동일하게 코드관리의 항목별 기준(`이름`)을 따릅니다.
- 우상단 **마스킹 해제** 시 성명도 함께 원문으로 보입니다(감사 로그 `PI_UNMASK` 기록, 비상연락망은 MANAGER도 해제 가능).
- 협력사도 함께 포함했습니다 — 외부 업체 직원이지만 마찬가지로 실제 개인 성명이기 때문입니다(현재 등록 0건이라 화면상 변화는 없습니다).

## 5. 사용자 매뉴얼 화면 캡처 전면 갱신

매뉴얼 스크린샷이 v1.4.0(2026-07-09) 이후 갱신되지 않아 현재 화면과 달랐습니다.

- **기존 36개 이미지를 최신 화면으로 교체**했습니다.
- **그림이 없던 화면 8개를 새로 추가**했습니다 — 소스 취약점 점검(SAST), 보안성 심의, 운영현황관리, 비상연락망, 보안용어집, 관련 사이트, 재해복구·BCP 훈련, 성능관리.
- 로그인 화면과 **등록 팝업 3종**(정책·취약점·자산) 캡처를 추가했습니다. 등록 화면은 v1.7.0 에서 팝업으로 바뀌었는데 초기 캡처가 하위호환용 페이지 폼이어서 다시 촬영했습니다.
- 매뉴얼 변경 이력에서 누락돼 있던 **v1.27.0 ~ v1.31.0 다섯 개 릴리즈**를 채웠고, 존재하지 않는 버전 표기(`인라인 필터 (v1.50.0 신규)`)를 정리했습니다.
- 매뉴얼에 **화면 넓게 보기** 사용법을 추가했습니다 (20. 환경설정 > 화면 탭).

## 업그레이드 방법

```bash
docker compose build frontend && docker compose up -d frontend
```

DB 마이그레이션 없음. 배포 후 브라우저 **하드 리프레시(Ctrl+Shift+R)** 가 필요합니다.

## 검증 범위

- `vite build` 컴파일 통과, 프론트엔드 이미지 빌드·배포 완료, nginx 가 새 번들(`index-*.js`)을 서빙하는 것까지 확인했습니다.
- **로그인이 필요한 화면에서의 실제 동작(접기·펴기 애니메이션, 단축키, 환경설정 스위치)은 화면에서 확인이 필요합니다** — 이 저장소에는 자동 테스트가 없고 캡처용 계정 로그인이 이 세션에서 불가했습니다.
