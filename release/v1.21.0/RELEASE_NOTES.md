# v1.21.0 릴리즈 노트

**릴리즈 일자**: 2026-07-25

**보안용어집** 메뉴를 신설했습니다.
보안 실무와 교육에서 자주 쓰는 용어를 한글·영문·약어·분류·정의로 정리해 한 곳에서 찾아볼 수 있고,
내용은 **관리 > 코드 관리 > 용어집** 탭에서 관리합니다.

## 신규 기능

### 보안 가이드 및 자료 > 보안용어집

보안문서 아래에 **보안용어집** 메뉴가 추가되었습니다. 로그인한 사용자 누구나 조회할 수 있습니다.

기본 제공 용어는 **178개**이며, **20개 분류**로 나뉩니다.

> 접근통제 · 보안원칙 · 위험관리 · 보안관리 · 네트워크 보안 · 암호기술 · 악성코드 · 사회공학 · 물리보안 · 애플리케이션 보안 · 공급망 보안 · 취약점 표준 · 사고대응 · 복구·연속성 · 데이터 보호 · 로그·감사 · 클라우드 보안 · 개발보안 · 위협 인텔리전스 · 보안위협

#### 찾는 방법

| 방법 | 설명 |
|------|------|
| **통합 검색** | 한글 용어 · 영문 표기 · 약어 · 분류 · 의미 · 관련 키워드를 한 번에 검색 (예: `MFA`, `암호화`, `phishing`) |
| **분류 필터** | 분류 버튼으로 좁혀보기 — 버튼마다 해당 분류의 용어 수 표시 |
| **약어 색인** | AAA · IAM · SIEM · EDR 등 **87개 약어**를 버튼으로 나열, 누르면 그 약어로 검색 |
| **키워드 태그** | 용어 아래 관련 키워드를 누르면 그 값으로 다시 검색 |

- 목록은 **분류별로 묶여** 표시되며, 각 용어는 `한글 용어 · 약어 배지 · 영문 표기 · 의미 · 관련 키워드` 순으로 나옵니다.
- 검색·필터는 화면에서 즉시 반영됩니다(서버 왕복 없음).
- ADMIN 계정에는 우측 상단에 **용어 관리 (코드 관리) →** 바로가기가 표시됩니다.

### 관리 > 코드 관리 > 용어집

코드 관리에 **용어집** 탭이 추가되었습니다(총 9개 탭).

- 용어별 **한글 용어 · 영문 표기 · 약어 · 분류 · 의미 · 관련 키워드 · 정렬 순서 · 사용 여부**를 등록·수정·삭제합니다.
- **관련 키워드**는 쉼표로 구분해 입력하며, 용어집 화면에서 태그로 표시되고 클릭 시 재검색됩니다.
- 분류는 기존 값 자동완성(datalist)을 제공하고, 통합 검색·분류 필터·20건 페이지네이션을 지원합니다.
- **한글 용어는 중복 등록할 수 없습니다**(대소문자 무시).
- 관리 화면에서는 **미사용 용어도 함께** 보여 상태를 확인할 수 있습니다.

> **삭제보다 미사용을 권장합니다.** 용어를 **모두 삭제하면 다음 기동 시 기본 용어 178건이 다시 생성**됩니다(신규 설치·구 볼륨·DB 재생성 대비 자동 복구 시더). 쓰지 않는 용어는 **사용** 체크를 해제하면 용어집 화면에서 제외됩니다. 삭제 확인 창에도 같은 안내가 표시됩니다.

## 권한

- 조회는 로그인 사용자, **등록·수정·삭제는 ADMIN 전용**입니다.
- RBAC 메뉴 키 **`glossary`** 가 추가되었습니다(총 44개). 권한관리 > 기본 역할 권한과 커스텀 Role에서 메뉴별로 제어할 수 있습니다.
- 용어 등록·수정·삭제는 **감사로그**(`GLOSSARY_TERM`)에 기록됩니다.

## API 변경

| 메서드 | 경로 | 설명 |
|--------|------|------|
| `GET` | `/api/glossary?keyword=&category=&activeOnly=` | 용어 목록 (기본 activeOnly=true) |
| `GET` | `/api/glossary/summary` | 총 건수 · 분류별 건수 · 약어 보유 수 |
| `POST` | `/api/glossary` | 용어 등록 (ADMIN) |
| `PATCH` | `/api/glossary/{id}` | 용어 수정 (ADMIN) |
| `DELETE` | `/api/glossary/{id}` | 용어 삭제 (ADMIN) |

## 데이터베이스

- 신규 테이블 **`glossary_terms`** — **ddl-auto 로 자동 생성**되므로 별도 마이그레이션이 필요 없습니다.
- `GlossaryInitializer`(seed-when-empty)가 테이블이 비어 있을 때만 기본 용어를 시드합니다. 이미 있으면 건너뛰므로 관리자가 수정한 내용은 재기동해도 보존됩니다.
- 참고 자료(`docs/security_in_computing_glossary.xlsx`)에서 Java 상수를 만드는 `scripts/gen_glossary_defaults.py` 를 함께 제공합니다. 자료가 갱신되면 스크립트를 다시 실행합니다.

## 업그레이드

```bash
git pull

```

```
[용어집] 보안 용어 178건 초기화
```
