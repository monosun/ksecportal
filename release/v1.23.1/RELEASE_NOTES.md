# v1.23.1 릴리즈 노트

**릴리즈 일자**: 2026-07-27

**관련 사이트** 화면의 목록 배치를 정리했습니다.

## 변경 사항

### 보안 가이드 및 자료 > 관련 사이트

- **한 열 목록** — 2열 그리드에서 한 열로 바꿔 위에서 아래로 차례대로 읽도록 했습니다.
- **내용 없는 사이트는 한 줄로 축약** — 게시물도 사이트 소개문도 가져오지 못한 사이트(외부 접속 차단·수집 실패 등)는 본문·상태 영역 없이 **헤더 한 줄**(이름 · 분류 · 도메인 · 설명 · 수집 상태 · 바로가기 · 관리 버튼)만 표시합니다. 빈 안내 박스가 카드 높이를 차지하지 않습니다.
- **게시물 행 정리** — 제목과 게시일을 한 줄에 나란히 두고, 요약은 한 줄로 줄였습니다.

문서: 사용자 매뉴얼 `10.2 관련 사이트` 의 화면 구성 설명을 위 내용에 맞춰 갱신했습니다.

## 업그레이드 안내

- 프론트엔드만 변경되었습니다. 배포 후 브라우저 **하드 리프레시(Ctrl+Shift+R)** 가 필요합니다.
