# KSecPortal v1.45.1 릴리즈 노트

**릴리즈 일자**: 2026-11-08

소스 취약점 점검(보안 운영 > 소스 취약점 점검)의 **점검 이력을 여러 건 한 번에 삭제**할 수 있습니다.

---

## 1. 점검 이력 일괄 삭제

- 점검 이력 목록 각 행 앞에 **체크박스** 추가 — 머리글 체크박스로 **현재 페이지 전체 선택·해제**(일부만 선택하면 중간 상태 표시)
- 목록 위 **선택 삭제 (N)** 버튼으로 확인 후 한 번에 삭제 — 그 점검의 발견 항목도 함께 삭제되며 되돌릴 수 없습니다
- 보고 있던 상세 점검이 삭제되면 상세 영역을 닫고, 마지막 페이지를 모두 지우면 앞 페이지로 이동합니다
- 페이지를 옮기면 보이지 않는 행의 선택은 자동 해제됩니다
- MANAGER 이상만 체크박스·선택 삭제가 보입니다(기존 행별 삭제와 동일 권한). 건별로 감사 로그 `SOURCE_SCAN_DELETED` 를 남깁니다

## 2. 소스 취약점 점검 오탐 조치

v1.45.0 공격 탐지 화면 라벨(`detectionLabels.js` 7·18행 `HONEYTOKEN: '…'`)이 `SAST-HARDCODED-SECRET`(CWE-798) 규칙의 `token: '…'` 패턴에 걸려 **높음 2건**으로 보고되던 오탐을 `// sast:ignore` 억제 주석으로 정리했습니다. 탐지 유형 이름의 한글 표시 문구일 뿐 자격증명이 아니며, 실제 허니토큰 값은 서버가 무작위로 생성해 DB 에만 저장합니다.

## 3. DB 변경 — 없음

## 4. 업그레이드

```bash
git pull
docker compose build backend frontend
docker compose up -d backend frontend
```

배포 후 브라우저 강력 새로고침(Ctrl+Shift+R).

## API

- `DELETE /api/source-scan/scans?ids=1,2,3` *(MANAGER+)* — 점검 이력 일괄 삭제(최대 500건, 없는 ID 는 건너뜀) → `{ "deleted": 3 }`
