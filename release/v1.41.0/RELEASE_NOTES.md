# KSecPortal v1.41.0 릴리즈 노트

**릴리즈 일자**: 2026-09-09

**보안 운영 > 보안성 심의**에서 심의가 끝난 건을 **결과 보고서 PDF**로 바로 보고, 내려받고, 출력할 수 있게 했습니다.
지금까지 심의 결과는 화면에서만 확인할 수 있어, 결재를 올리거나 감사·인증 심사에 제출할 때는
화면을 캡처하거나 내용을 따로 옮겨 적어야 했습니다.
이제 **미리보기 → 인쇄 / 다운로드**가 심의 화면 안에서 끝납니다.

---

## 1. 심의 결과 보고서 (신규)

### 여는 방법

- **목록** — 심의가 완료된 행의 상태 배지 옆 **보고서** 링크
- **상세 > 심의 결과** — **결과 보고서** 버튼(미리보기) 또는 **PDF 내려받기**(미리보기 없이 바로 저장)

미리보기 창 오른쪽 위에서 **인쇄**로 바로 출력하고, **다운로드**로 파일을 저장합니다.
내려받는 파일명에는 심의 제목이 함께 들어가 여러 건을 받아도 구분됩니다.

### 보고서 구성 (세로 A4)

| 구성 | 내용 |
|------|------|
| 표지 | 보고서 제목 · 회사명(설정관리) · 대상 시스템 · 심의일 |
| 심의 결과 | **승인(초록) / 조건부 승인(노랑) / 반려(빨강)** 배너와 심의자·심의일시 |
| 1. 심의 개요 | 심의 제목·대상 시스템·심의 구분·요청 부서·요청자·요청일·오픈 예정일·설계서 첨부·개인정보 처리·외부 공개, 구축·변경 개요 |
| 2. 검토 결과 요약 | 검토 항목·적합·부적합·해당없음·미검토 건수 타일과 **검토 영역별 현황표**(영역별 부적합은 붉게 강조) |
| 3. 설계 검토 체크리스트 | 영역 · 검토 항목 · 검토 기준 · 결과 · 검토 의견 (등록된 전 항목) |
| 4. 심의 의견 | 심의 결과 등록 시 남긴 승인 조건·보완 요구사항 |
| 끝 | 심의자 · 심의일시 · 출력일 |

기존 보고서와 같은 나눔고딕 임베딩·표 서식을 사용해 인쇄물에서도 한글이 깨지지 않습니다.

### 만들 수 있는 시점

**심의 완료(`COMPLETED`)** 건만 보고서를 만듭니다.
요청 접수·검토중·보완 요청 상태에서는 결과와 심의자가 확정되지 않아
`심의가 완료된 건만 보고서를 만들 수 있습니다.` 로 막습니다.

### 권한

다른 보고서(취약점·자산·개인정보 등)는 MANAGER 이상이지만,
**이 보고서는 로그인한 사용자면 받을 수 있습니다.**
같은 내용을 심의 상세 화면에서 이미 볼 수 있으므로 열람 권한과 맞춘 것으로, 새로 열리는 정보는 없습니다.

## 2. 파일 미리보기 창에 인쇄 버튼

공용 미리보기 컴포넌트(`FilePreviewModal`)에 **인쇄** 버튼을 옵션(`printable`)으로 추가했습니다.
보고서처럼 바로 출력해야 하는 화면만 켜서 쓰며, **보안 가이드 및 자료 등 기존 사용처의 화면은 그대로입니다.**
브라우저 PDF 뷰어가 창 안에서의 인쇄를 막는 경우에는 **새 탭으로 열어** 인쇄할 수 있게 대체합니다.

## DB 변경

**없습니다.** 기존 `security_reviews` · `security_review_items` 를 그대로 읽어 보고서를 만듭니다.

## 알려진 제약

- **심의 완료 건만** 보고서를 만들 수 있습니다.
- 보고서는 만들 때마다 새로 생성됩니다(파일로 보관하지 않음). 심의 내용을 고치면 다음 출력부터 반영됩니다.
- **인쇄**는 브라우저 PDF 뷰어에 맡깁니다. 뷰어가 창 안에서의 인쇄를 막으면 새 탭으로 열리며, 그 탭에서 인쇄하면 됩니다.
- 검토 항목이 많으면 보고서가 여러 쪽으로 나뉩니다(표 머리글은 쪽마다 반복).

## 업그레이드

```bash
git pull
docker compose build backend frontend
docker compose up -d backend frontend
```

- 배포 후 브라우저 **하드 새로고침(Ctrl+Shift+R)** 이 필요합니다.
