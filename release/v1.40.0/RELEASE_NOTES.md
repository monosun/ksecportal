# KSecPortal v1.40.0 릴리즈 노트

**릴리즈 일자**: 2026-09-09

**ISMS-P 통제항목 매핑**을 엑셀로 **내려받아 한 번에 고친 뒤 다시 올릴 수 있게** 했습니다.
지금까지는 통제항목마다 행을 펼쳐 정책(장)·조를 하나씩 클릭해 걸어야 했습니다.
101개 통제항목에 지침 여러 장·조를 처음 매핑하거나, 지침 개정으로 매핑을 한꺼번에 손볼 때는
클릭 수가 수백 번에 달했습니다. 이제 **매핑 내보내기 → 엑셀 편집 → 일괄 업로드** 한 번으로 끝납니다.

---

## 1. 매핑 내보내기 (현재 등록된 매핑 엑셀 다운로드)

**보안 관리 > ISMS-P 통제항목 매핑** 화면 오른쪽 위 **매핑 내보내기** 버튼으로
현재 등록된 매핑 전체를 엑셀(`.xlsx`)로 내려받습니다.

- **매핑 1건이 1행**입니다. 한 통제항목에 여러 정책·조가 걸려 있으면 항목코드가 여러 행에 반복됩니다.
- 매핑이 **없는 항목도 정책 열이 빈 행**으로 함께 실려, 어디가 비어 있는지 한 파일에서 확인할 수 있습니다.
- `정책ID`·`조ID` 열이 자동으로 채워져 있어, **이 파일을 그대로 고쳐 다시 올리면** 정확히 같은 대상을 찾습니다.
- 시트 3장: `매핑목록` / `입력규칙` / `정책·조 목록(참고)`.

## 2. 매핑 일괄 업로드 (템플릿 제공)

**일괄 업로드** 버튼(관리자·담당자)으로 창을 열어 **템플릿 다운로드**(빈 양식) 또는
**매핑 다운로드**(현재 매핑이 채워진 양식)를 받아 채운 뒤 올립니다. `.xlsx`·`.csv` 모두 지원합니다.

### 시트 열 구성

내보내기·템플릿·업로드가 **같은 열 순서**를 공유하므로 내려받은 파일을 그대로 올릴 수 있습니다.

| 열 | 내용 | 업로드 시 |
|----|------|-----------|
| **항목코드** | ISMS-P 통제항목 코드(예: `1.1.1`) | **필수** |
| 항목명(참고) · 도메인(참고) | 사람이 보기 위한 열 | 읽지 않음 |
| 지침명 | 예: `개인정보보호 지침` | 같은 제목의 장이 여러 건일 때 구분에 사용 |
| **정책(장) 제목** | 연결할 정책(장)의 제목 | 정책ID·조ID가 없을 때 사용 |
| 조 표기 | `제12조` 처럼 적으면 **그 조만** 매핑, **비우면 장 전체** 매핑 | 선택 |
| 조 제목(참고) | 조 제목 | 읽지 않음 |
| 정책ID(선택) · 조ID(선택) | 내보내기 시 자동으로 채워짐 | 있으면 제목보다 **우선** |

- 매핑 대상은 **조ID → 정책ID → 제목** 순으로 해석합니다. 조ID가 있으면 소속 장은 조에서 따라갑니다.
- 정책ID·조ID를 모르면 `정책·조 목록(참고)` 시트에서 찾아 복사해 쓰면 됩니다.
- 같은 제목의 장이 여러 건이면 `지침명`으로 좁히고, 그래도 가려지지 않으면
  **"지침명 또는 정책ID 열을 채워주세요"** 로 그 행만 실패 처리합니다.
- 정책 열이 모두 빈 행은 **매핑 없음**으로 보고 건너뜁니다(대상 건수에도 세지 않습니다).
- 이미 등록된 매핑은 **중복 등록하지 않고** `중복` 으로 셉니다.

### 기존 매핑 대체

업로드 창의 **기존 매핑 대체** 체크박스를 켜면,
**파일에 나온 항목코드의 기존 매핑을 모두 지운 뒤** 파일 내용으로 다시 등록합니다.
내보낸 파일에서 필요 없는 행을 지우고 이 옵션으로 올리면 **매핑 삭제까지 한 번에 반영**됩니다.
끄면(기본값) 새 매핑만 더해지므로 기존 매핑은 그대로 남습니다.

### 결과 확인

업로드가 끝나면 **대상 / 등록 / 중복 / 실패** 건수와,
실패한 행의 **엑셀 행 번호·항목코드·사유**가 표에 표시됩니다.
대체 모드에서는 지운 기존 매핑 건수와 다시 등록한 항목 수도 함께 알려 줍니다.
등록·삭제가 있었으면 화면의 매핑 현황이 곧바로 갱신됩니다.

## DB 변경

**없습니다.** 기존 `isms_policy_mappings` 테이블을 그대로 사용하며 마이그레이션이 필요 없습니다.

## 알려진 제약

- 업로드는 **관리자·담당자(MANAGER 이상)** 권한이 필요합니다. 내보내기는 조회 권한이면 가능합니다.
- 매핑 대상은 **이미 등록된 정책(장)·조**만 지정할 수 있습니다. 파일에 새 정책을 적어도 정책이 생성되지는 않습니다.
- `조 표기`로 조를 지정하려면 그 정책의 본문이 `### 제N조(제목)` 형식으로 조까지 나뉘어 있어야 합니다.
- **기존 매핑 대체**로 지운 매핑은 되돌릴 수 없습니다. 실행 전에 **매핑 내보내기**로 현재 상태를 먼저 받아 두세요.

## 업그레이드

```bash
git pull

docker compose up -d backend frontend
```
