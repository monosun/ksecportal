# KSecPortal v1.37.0 릴리즈 노트

**릴리즈 일자**: 2026-08-18

보안 정책을 **문서 파일에서 바로 등록**할 수 있게 했습니다. 지침 문서(PDF·DOCX) 한 개를 올리면
**지침 &gt; 장(章) &gt; 조(條)** 구조로 나눠 등록되고, 개별 정책도 문서 파일로 채울 수 있습니다.
더불어 ISMS-P 통제항목 매핑에서 **조 번호·조 제목으로 찾아 한 번에 매핑**할 수 있습니다.

---

## 1. 지침 문서 등록 — 지침 &gt; 장 &gt; 조 자동 구성

보안 정책 목록 우상단 **`지침 문서 등록`** 버튼이 생겼습니다.
지침 문서 하나를 올리면 **장별로 정책이 나뉘어 등록**되고, 각 장 안의 **조까지 자동 세분화**됩니다.

- 지원 형식: **PDF · DOCX · TXT · MD** (최대 20MB). PDF 본문 추출은 Apache PDFBox 를 씁니다.
- **지침명**은 문서 제목 줄이나 파일명에서 자동 인식하며, 직접 입력할 수도 있습니다.
  카테고리·상태·버전·시행일은 장별 정책에 공통 적용됩니다.
- **미리보기** 버튼으로 *어떤 장이 몇 개 조로 등록될지* 먼저 확인한 뒤 등록합니다(저장하지 않는 `dryRun`).
- 정책 제목을 `지침명 - 제N장 장제목` 으로 맞추므로, 기존 등록 경로와 **똑같이** 지침명·장 컬럼과
  조 레코드가 채워집니다. 등록 직후 **조문 검색**과 **ISMS-P 통제항목 매핑**에서 조 단위로 바로 쓸 수 있습니다.

### 이미 있는 장은 본문만 갱신 — ISMS-P 조 매핑 유지

같은 제목의 장이 이미 있으면 **본문만 갱신**합니다(미리보기에 `갱신` 배지로 표시).
조 레코드는 조 표기 기준으로 재사용되므로 **ISMS-P 통제항목에 걸어둔 조 단위 매핑이 끊기지 않습니다.**

### 목차·쪽번호·머리말 자동 제외

문서를 그대로 읽으면 목차의 `제1장 …`, `제1조(…)` 가 본문의 장·조로 잡혀 **빈 껍데기 장이 등록**됩니다.
이를 막기 위해 등록 전에 다음을 걷어냅니다.

| 대상 | 판별 방식 |
|------|----------|
| **목차** | `목 차`·`차례`·`CONTENTS` 머리글부터, 목차에 실린 장·조 머리글이 **본문에서 다시 나오는 지점**까지 (쪽번호가 없는 목차도 걸러집니다) |
| **차례 줄** | `제1조(목적) ……… 3` 처럼 점선이나 쪽번호가 붙은 줄 — 목차 머리글이 없는 문서에서도 제외 |
| **쪽번호** | `12`, `- 12 -`, `12 / 40`, `Page 12` |
| **머리말·꼬리말** | 절반 이상의 쪽에서 위·아래 2줄에 되풀이되는 줄 |

제외한 목차 줄 수는 **"목차로 보이는 N줄을 제외했습니다."** 로 안내합니다.
본문을 잘못 지우지 않도록, 끝에 숫자가 붙은 줄은 **장·조 머리글이면서 60자 이하일 때만** 목차로 봅니다.
본문 문장의 `② 제3조의 규정에 따라 …` 는 조 제목 괄호가 없어 조로 잡히지 않습니다.

| 상황 | 처리 |
|------|------|
| 장(제N장) 머리글이 없는 문서 | 문서 전체가 정책 1건으로 등록(안내 표시) |
| 조 머리글이 없는 문서 | 본문 전체가 `전문` 한 건으로 등록 |
| 첫 장 앞의 제정·개정 이력 | 첫 장 본문 앞에 함께 보존 |

## 2. 개별 정책 — 문서 파일로 등록

정책 등록 팝업 맨 위에 **`문서 파일로 등록`** 영역이 생겼습니다.

- 파일을 고르면 **제목과 내용이 자동으로 채워집니다.** 확인·수정한 뒤 평소대로 저장하면 조가 세분화됩니다.
- 이미 입력한 내용이 있으면 **덮어쓸지 먼저 확인**합니다.
- 문서에서 장이 여러 개 발견되면 `지침 문서 등록` 을 쓰라고 안내합니다.

## 3. ISMS-P 통제항목 매핑 — 조 번호·조 제목으로 찾아 한 번에 매핑

정책 추가 검색창에 **2자 이상** 입력하면 정책(장) 목록 위에 **`조 검색 결과`** 가 뜹니다.

- `제5조` 같은 **조 번호**, `접근권한` 같은 **조 제목**으로 찾습니다.
- 각 줄에 `제N조` 배지 + 조 제목, 아래에 **지침 &gt; 장** 경로를 표시합니다.
- **누르면 그 조만 즉시 매핑**됩니다 — 장을 찾아 `조 N` 버튼으로 펼치는 단계가 없어집니다.
- 이미 매핑된 조는 `매핑됨` 으로 비활성 표시, 상위 30건까지 표시(초과 시 안내).
- 250ms 디바운스와 순번 검사로, 늦게 도착한 이전 응답이 결과를 덮지 않습니다.

기존 **장 전체 매핑**과 **조 펼쳐 고르기** 는 그대로입니다.

## API 변경

| 엔드포인트 | 내용 |
|-----------|------|
| `POST /api/policies/documents/extract` *(MANAGER+)* | **신규** — 문서에서 제목·본문 초안 추출(저장 안 함) |
| `POST /api/policies/documents/import` *(MANAGER+)* | **신규** — 지침 문서를 장별 정책으로 등록. `dryRun=true` 면 미리보기 |
| `GET /api/policies/articles` | 검색 범위(`scope`)에 **`HEADING`**(조 표기 + 조 제목) 추가 |

`HEADING` 은 조문 검색 탭의 범위 드롭다운에도 **`조 표기 + 조 제목`** 으로 추가했습니다.

## DB 변경

**없습니다.** 마이그레이션도 필요하지 않습니다.

## 알려진 제약

- **스캔 이미지로만 된 PDF** 는 글자가 없어 읽지 못합니다(안내 메시지 반환). OCR 은 지원하지 않습니다.
- **한글 파일(`.hwp`/`.hwpx`)과 구형 `.doc`** 은 지원하지 않습니다 — PDF 나 DOCX 로 변환해 올려주세요.
- 표가 많거나 단(段)이 나뉜 PDF 는 줄 순서가 흐트러질 수 있습니다. **미리보기로 장·조 개수를 먼저 확인**하세요.

## 업그레이드

```bash
git pull
docker compose build backend frontend
docker compose up -d backend frontend
```

- 백엔드에 **PDFBox 의존성이 추가**되어 이미지 재빌드가 필요합니다(빌드 시 의존성 다운로드).
- DB 마이그레이션은 없습니다.
- 배포 후 브라우저 **하드 새로고침(Ctrl+Shift+R)** 이 필요합니다.
- 운영 환경에서는 배포 전 **DB 백업**을 먼저 수행하세요.
