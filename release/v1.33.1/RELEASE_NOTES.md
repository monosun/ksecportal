## 2. 운영 배포 시 주의사항 문서화

`README.md` 의 **업그레이드** 절에 **운영 배포 시 주의사항** 표를 추가했습니다.

- 배포 전 DB 백업 (마이그레이션은 되돌리는 스크립트가 없음)
- **마이그레이션은 백엔드 재기동 전에 수동 적용** — `ddl-auto: update` 는 컬럼 추가만 하고 백필·제약 변경은 하지 않음
- `db/init/*.sql` 은 빈 볼륨(신규 설치)에서만 실행 — 운영 인스턴스는 `db/migration` 필수
- **`nginx/nginx.conf` 변경 시 frontend 이미지 재빌드 필수** (설정이 이미지에 복사됨)
- 업로드 한도는 nginx `client_max_body_size` 와 백엔드 `MAX_FILE_SIZE` **양쪽을 함께** 조정
- 시더는 "비어 있을 때만" 동작 — 기존 데이터가 있으면 신규 기본 항목이 자동 반영되지 않음
- 배포 후 기동 로그 확인과 브라우저 하드 새로고침, `[보안점검]` 경고 항목 교체
- **롤백해도 적용된 DB 마이그레이션은 되돌아가지 않음**

같은 내용을 v1.33.0 릴리즈 노트의 **적용 방법** 절에도 반영했습니다.

---

## 적용 방법

```bash
docker compose build frontend
docker compose up -d frontend
```

매뉴얼과 이미지는 frontend 이미지 빌드 시 `docs/` 에서 `public/help/` 로 복사되므로, 도움말 화면에 반영하려면 frontend 재빌드가 필요합니다. 배포 후 브라우저 하드 새로고침(Ctrl+Shift+R).
