# KSecPortal v1.25.0 릴리즈 노트

릴리즈 일자: 2026-08-01

## 요약

퀴즈 문항의 보기를 **A~E(최대 5지선다)** 까지 확장했습니다. 기존 4지선다 문항은 그대로 동작하며, 보기 E는 선택 입력입니다. 정답이 `E`를 포함한 문항(`AE`, `BCE`, `ABE` 등)도 엑셀 일괄등록으로 그대로 등록할 수 있습니다.

위협 카탈로그에는 **대상 자산유형(복수 선택)** 항목과 **Excel 다운로드**를 추가하고, 등록된 위협 전건에 자산유형을 일괄 할당했습니다.

## 상세

### 퀴즈 보기 E 추가 (5지선다 지원)

- 문제은행·교육 문항에 **보기 E** 추가 — 보기 A·B는 필수, C~E는 선택. 보기 E를 비워 두면 기존과 동일한 4지선다 문항입니다.
- 정답 지정 버튼이 A~D → **A~E** 로 확장. 복수 정답도 동일하게 동작하며, 내용이 없는 보기는 정답으로 지정할 수 없습니다.
- 채점은 기존과 같이 **정답 보기를 모두 정확히 선택해야 정답**(집합 비교)입니다. 응시 화면은 보기 E가 있는 문항만 5개 선택지를 노출합니다.
- 정답 검증 메시지를 `정답은 A~E 중 하나 이상이어야 합니다.` 로 변경.

### 엑셀 일괄등록·다운로드 양식

- 템플릿에 **보기E** 열 추가(총 10열) — `분류 / 난이도 / 문제 / 보기A / 보기B / 보기C / 보기D / 보기E / 정답 / 해설`.
- 정답 열 헤더를 `정답(A~E, 복수는 A,B 또는 AB)*` 로 변경 — 복수 정답은 `A,B` 처럼 콤마로 구분하거나 `AB` 처럼 붙여 써도 인식합니다(`a b`·`A/B` 도 동일).
- **예전 9열 양식(보기E 없음) 파일도 그대로 업로드 가능** — 헤더의 8번째 열이 `보기E` 인지 보고 양식을 자동 판별해 정답·해설 열 위치를 잡습니다.
- 문항 다운로드(전체/검색결과/선택)도 보기E 열을 포함한 동일 양식으로 저장돼 그대로 재업로드할 수 있습니다.

### 문제은행 상세 표시

- 문항을 펼쳤을 때 보기 A~E를 항상 표시하고, **내용이 없는 보기는 `-` 로 표기**합니다(기존에는 숨김). 응시 화면은 빈 보기를 선택지로 노출하지 않도록 종전대로 유지합니다.

### 위협 카탈로그 — 대상 자산유형(복수 선택)

- 위협 추가·수정 화면에 **대상 자산유형** 항목 신설 — **코드관리 `ASSET_TYPE` 그룹의 사용 중인 값**을 칩으로 표시하고 복수 선택할 수 있습니다. 선택하지 않아도 저장됩니다.
- 목록에 **대상 자산유형** 열 추가(배지 표시, 값이 없으면 `-`)와 인라인 필터 추가 — 특정 자산유형이 지정된 위협만 조회할 수 있습니다.
- 저장은 코드값을 콤마로 구분한 문자열(`threats.asset_types`), API는 문자열 배열(`assetTypes`)로 주고받습니다. 코드관리에서 값이 삭제되어도 이미 저장된 위협은 저장된 코드값을 그대로 표시합니다.
- **기존 위협 전건에 자산유형을 일괄 할당**했습니다(자산분류 기준 매핑, 아래 표). 기본 위협항목 마스터(`threat_defaults`)에도 동일하게 반영되어 **초기화·기본항목 추가 후에도 유지**됩니다.

### 위협 카탈로그 — Excel 다운로드

- 화면 상단에 **다운로드** 버튼 신설 — 필터가 걸려 있지 않으면 `전체 다운로드 (N건)`, 필터 적용 중에는 `검색결과 다운로드 (M건)` 로 바뀌어 현재 조회 중인 목록을 그대로 내려받습니다.
- 저장 항목: 위협명·유형·카테고리·대상 자산유형·자산분류·설명·발생가능성·잠재영향·위험점수·위험수준(낮음/중간/높음)·비고·등록일·수정일.

## 데이터베이스 변경

`quiz_bank_questions` · `quiz_questions` 에 `option_e VARCHAR(500) NULL` 추가, `correct_answer` 를 `VARCHAR(7)` → `VARCHAR(9)`(`A,B,C,D,E`) 로 확장.

`threats` · `threat_defaults` 에 `asset_types VARCHAR(500) NULL` 추가 — 신규 nullable 컬럼이라 `ddl-auto: update` 로 재기동 시 자동 생성됩니다. **기존 데이터에 자산유형을 채우려면 아래 백필을 실행**하세요(이미 값이 있는 항목은 건드리지 않습니다).

```bash
docker compose exec -T db mysql -usecportal -psecportal123 secportal < db/migration/v1.25.0_threat_asset_types.sql
```

신규 설치는 `db/init/09_threat_seed.sql` 에 동일한 할당이 포함되어 있어 별도 실행이 필요 없습니다.

```bash
docker compose exec -T db mysql -usecportal -psecportal123 secportal < db/migration/v1.25.0_quiz_option_e.sql
```

`db/init/01_schema.sql` 에도 반영되어 신규 설치는 마이그레이션이 필요 없습니다.

## 업그레이드

```bash
docker compose exec -T db mysql -usecportal -psecportal123 secportal < db/migration/v1.25.0_quiz_option_e.sql
docker compose build backend frontend
docker compose up -d backend frontend
```

배포 후 브라우저 하드 리프레시(Ctrl+Shift+R)가 필요합니다.
