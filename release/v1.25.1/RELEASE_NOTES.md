# KSecPortal v1.25.1 릴리즈 노트

릴리즈 일자: 2026-08-01

## 요약

위험평가의 **자산 자동 불러오기**가 자산과 위협을 무조건 전조합으로 생성하던 것을, **자산유형이 일치하는 조합만** 생성하도록 바꿨습니다. 자산 수 × 위협 수만큼 쏟아지던 평가 항목이 실제로 해당되는 조합으로 줄어듭니다.

## 상세

### 위험평가 — 자산유형 매칭

- 차수 생성 시 자동 불러오기(체크박스) 및 **자산 자동 불러오기** 버튼 모두, **자산의 자산유형이 위협의 대상 자산유형 중 하나와 일치하는 조합만** 평가 항목으로 생성합니다.
- **위협에 대상 자산유형이 지정되지 않은 경우**에는 자산유형을 가리지 않는 위협으로 보고 종전처럼 모든 자산에 적용합니다(기존 데이터 호환).
- 자산에 자산유형이 없으면, 대상 자산유형이 지정된 위협과는 매칭되지 않습니다.
- 이미 그 차수에 존재하는 자산×위협 조합은 건너뛰는 동작은 그대로입니다.
- 화면 안내 문구와 완료 메시지를 매칭 규칙이 드러나도록 수정했습니다(`평가 항목 N건이 추가되었습니다. (자산유형이 일치하는 자산×위협 조합)`).

## 데이터베이스 변경

없습니다. 위협의 대상 자산유형(`threats.asset_types`)은 v1.25.0에서 추가·백필되었습니다.

## 업그레이드

```bash
docker compose build backend frontend
docker compose up -d backend frontend
```

배포 후 브라우저 하드 리프레시(Ctrl+Shift+R)가 필요합니다. 이미 생성된 지난 차수의 평가 항목은 스냅샷이므로 이번 변경의 영향을 받지 않습니다.
